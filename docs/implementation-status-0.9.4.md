# 0.9.4 구현 상태

## 수정 원인

정·역회전·자기유지·인터록·EOCR 연습문제의 승인 스냅샷에는 `PWR`, `PB`, `RL`, `GL`, `M1` 외부선이 포함됩니다. 동작시험 결선판이 이 외부 단자를 내부 직교 경로 계산기에 전달하면서 좌표 조회 예외가 발생했습니다.

## 수정 사항

- 내부 단자끼리 연결된 전선만 직교 경로 계산기에 전달
- 외부 단자와 TB 연결은 TB5 위쪽 또는 TB6 아래쪽으로 별도 표시
- 내부 경로 계산기가 보드에 없는 외부 단자를 안전하게 제외하도록 방어 처리
- 결선이 없는 실제 정·역회전 문제의 초기 미리보기 회귀 테스트 추가
- 외부선 18가닥을 포함한 승인 결선 44가닥 동작시험 회귀 테스트 추가

기존 승인 스냅샷과 결선 초안은 삭제하거나 변환할 필요 없이 그대로 사용할 수 있습니다.
