# Q-Net 010 동작 검증 개발 인계

## 이번 변경

- 사용자 62선 후보를 운영 코드의 검증기, Net 비교, 안전검사, 기구·동작 엔진으로 다시 검사했다.
- 원문은 보존하고, 수정 후보는 `docs/private` 아래 비공개 개발 자료로 분리했다.
- PB, 타이머, 8P 교환접점, 4단자 이중 FUSE, EOCR 전원 조건에 공통 회귀 테스트를 추가했다.
- FUSE 공식 근거를 PDF 6~9쪽과 공개 검색으로 재검수했다.
- 배포 스크립트가 비공개 후보·감사 코드·비공개 테스트를 제외하고 공개 문제 답안 필드를 비식별화하도록 보강했다.
- 실제 브라우저에서 분석 자동저장, 결선 자동저장, 요구사항 검사, 고장시험, 자유회로 FUSE와 정답 비노출을 확인했다.

## 현재 상태

- 문제 010은 연습 및 무채점 동작시험이 가능하다.
- 결과는 요구사항별 `충족/미충족`만 표시하며 점수나 합격/불합격을 만들지 않는다.
- 기존 2단자 FUSE는 제공하지 않고 한 몸체의 2회로 4단자 FUSE만 사용한다.
- 사용자 원본 후보는 실제 동작 4/5이고, 비공개 수정 후보는 5/5이다.
- 정확한 FUSE 제조사·모델·공식 외부 번호가 없어 상태는 `draft / unverified`다.

## 후속 작업 순서

1. Q-Net 또는 실제 지급품의 제조사·모델·단자표를 확보해 FUSE 번호 근거를 보강한다.
2. 확보한 근거가 현재 구현과 일치할 때만 검증 상태 변경을 별도 변경으로 진행한다.
3. 다른 공개문제는 각각 공식 회로·동작 근거를 확보한 뒤 독립 브랜치에서 추가한다.
4. 공통 엔진 변경은 항상 부분 수정, 관련 회귀 테스트, 마지막 전체 테스트 순서로 수행한다.

## 보호 사항

- `docs/private`와 사용자 후보 감사 스크립트는 공개 배포 금지다.
- 공개 API, 프런트 번들, 일반 로그에 후보 전선 목록·내부 정답 Net을 넣지 않는다.
- 기존 SQLite, 사용자 작업공간, 자유회로와 결선 기록을 마이그레이션 없이 변경하지 않는다.
- 배포는 저장소 루트의 `pack-electrician-full-project.ps1`만 사용하고 생성된 수집 보고서를 확인한다.
