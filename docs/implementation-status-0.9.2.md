# 0.9.2 구현 상태

0.9.1의 기능과 데이터 구조를 유지한 화면 안정화 패치입니다.

## 수정 사항

- 외부 기구선이 있는 결선 화면을 `도구막대 / 외부 기구선 / 결선판`의 명시적인 3행 레이아웃으로 변경
- 창 최대화와 가로 폭 변경 시 외부 기구선이 결선판 뒤로 잘리는 현상 수정
- TB5 명칭을 단자대 상단 안쪽, TB6 명칭을 하단 안쪽으로 이동
- 단자대 명칭 박스의 최대 폭·높이와 글자 크기를 줄여 슬롯 번호 및 요약 배지와 분리
- 문제 JSON, 저장 결선, 채점 및 동작시험 데이터는 변경하지 않음

## 유지되는 제한 사항

- 저장소에는 자체제작 검증 회로 5개만 있으며 검증된 Q-Net 공개문제 데이터는 0/18입니다.
- Windows 실제 장치의 pywebview/WebView2 표시는 별도 수동 확인이 필요합니다.
