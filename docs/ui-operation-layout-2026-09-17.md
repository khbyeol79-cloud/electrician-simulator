# 회로도 하단 기호 입력과 동작시험 도면 표시

## 구현

- 공개문제 001~018의 하단 원형/사각형 기호를 각각 11개씩 입력 대상으로 추가했다. 기존 접점 ID는 유지한다.
- EOCR, FR, 표시등, 부저, 코일 기호를 클릭하면 위/아래 번호를 입력한다. 번호는 기호 바깥에 표시되며 기존 자동저장과 위치 조정 기능을 사용한다.
- 동작시험에서 제어함 결선 / 시퀀스 회로도 / 배관·배치도를 선택한다. 전환은 동작 세션을 재시작하지 않는다.
- 시퀀스 회로도에는 저장된 개인 분석 번호만 표시한다. 전류 흐름이나 동작 애니메이션은 추가하지 않았다.
- 배관도는 18개 원본 배치 이미지의 기구 위치를 각각 대조하여 표시등, BZ, PB, SS 위치를 등록했다. 표시 상태는 실제 세션의 indicators / audible_outputs / controls만 사용한다.
- 모터 정·역회전은 하단 상태 범례에 표시한다. 모터 위치를 TB 위치로 추측해 그림 위에 배치하지 않는다. BZ는 시각적인 울림 표시만 제공하며 소리는 출력하지 않는다.
- 공통 회로 엔진, 문제 정답, 사용자 답안 후보, SQLite 스키마는 수정하지 않았다.

## 프로그램 직접 확인

별도 검증용 닉네임 `화면검증0917`에서 새 작업공간 `사용자 답안 2`를 만들었다. 기존 사용자의 결선은 덮어쓰지 않았다.

1. Q001 분석 화면에서 하단 EOCR 6/12, BZ 1/2를 입력하고 저장 및 기호명 비가림을 확인했다.
2. GUI에서 전원 → TB → 4단자 FUSE → TB → YL/BZ의 10선 시험 결선을 직접 작성했다. 이것은 표시 기능 시험용이며 Q001 정답이 아니다.
3. 전원 ON: YL 점등, BZ 울림이 실제 엔진 상태와 배관도에 함께 표시됐다.
4. FUSE 1-2 단선: YL 소등. 복구: 다시 점등됐다.
5. SS 자동/수동 전환: 배관도 레버와 상태가 변경됐다.
6. 시퀀스 회로도로 전환해도 전원 상태가 유지됐고 저장된 분석 표시 6개가 보였다. 동작 오버레이는 없었다.
7. 전원 OFF: YL 소등과 BZ 정지 확인. 시험 종료 시 전원은 꺼두었다.

모든 18문제의 회로 동작 전체를 수동 검증했다는 의미는 아니다. 이번 UI 시험은 Q001의 별도 시험 결선으로 수행했다. 모터 회전 표시는 자동 테스트로 검증했다.
