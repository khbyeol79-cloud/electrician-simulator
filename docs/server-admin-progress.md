# LAN 서버 관리 페이지 작업 기록

기준: `9d6a180`, `feature/qnet-all-wiring-capture`, 2026-09-20.

후속 작업: 관리자 비밀번호 재설정 및 간편 서버 종료·USB ZIP 백업은 [추가 작업 기록](server-stop-backup-progress.md)을 참고한다. 아래 내용은 최초 관리자 페이지 구현 시점의 기록이다.

## 범위

- 시뮬레이터의 `/admin`에 운영 상태·수신 설정·가입 허용·계정 세션·저장 경로·백업 안내를 통합한다.
- 웹 요청으로 서버/방화벽/공유기를 제어하지 않는다. 현재 실행 서버나 실제 사용자 계정의 권한을 임의 변경하지 않는다.
- 관리자 지정은 서버 PC의 기존 계정 대상 오프라인 명령으로만 제공한다. 첫 가입자 자동 승격 금지.
- 회로 엔진·문제 정의·원본 답안·기존 학습 SQLite 내용은 수정하지 않는다.

## 구성

- `backend/app/api/admin.py`: 권한 검사 및 상태/계정 목록, 가입 허용, 다음 실행 네트워크 설정, 계정 세션 종료 API.
- `backend/app/core/auth.py`: 기존 계정 스키마 보존 + 관리자/서비스 설정/관리 이력 테이블 추가. 관리자 지정·해제 시 세션 폐기.
- `backend/app/core/service_admin.py`: RFC1918/로컬 IPv4·포트 검증, 관리 실행기의 설정 읽기, 가입 허용 조회.
- `scripts/run_service.py`: 중지 후 재시작할 때 저장된 네트워크 설정 적용. `scripts/manage_admin.py`: 관리자 지정/해제 및 네트워크 설정 복구.
- `frontend/src/pages/ServerAdminPage.tsx`, `api/admin.ts`, `styles/server-admin.css`: 관리자 대시보드·설정·확인창. 일반 학습자에게 메뉴/데이터 요청 비노출.
- 관리 설정/권한은 `accounts.db` 안에 보관하여 기존 백업·복원 경로로 함께 이전한다.

## 실제 브라우저 검증

- 별도 임시 데이터와 시험용 계정만 사용. localhost:8021의 관리자 로그인, 상태/계정 목록 확인, 신규 가입 닫기 즉시 반영 확인.
- 화면에서 시험 포트를 8022로 저장하고 기존 8021 수신과 ‘재시작 필요’ 표시가 유지되는 것을 확인했다. 시험 서버만 종료/재실행하여 실제 localhost:8022 접속과 저장된 가입 닫힘 상태, 관리자 권한 유지 확인.
- 일반 학습자 계정으로 같은 `/admin`에 로그인하면 ‘서버 관리자 전용’만 표시되고 관리 메뉴는 노출되지 않음.
- 390px 휴대폰 크기에서 그리드 최소 폭 때문에 가로 넘침이 발생하여 관리자 경로의 그리드 폭만 보완. 재검사 시 viewport/pageWidth 375px 동일, 가로 넘침 없음. 데스크톱/모바일 실제 화면 확인 후 원래 뷰포트 복원.
- 시험용 브라우저 탭과 Python 서버만 종료했다. Codex 앱·사용자의 운영 서버는 종료하지 않았다.

## 남은 운영 절차

- 실제 관리자 아이디는 사용자가 선택해야 하며 아직 지정하지 않았다. 실행 중 운영 서버의 주소·포트·계정 권한이나 기존 학습 기록을 변경하지 않았다.
- 관리자 지정/재로그인 및 관리 실행기로 재시작하는 절차는 `lan-classroom-service.md`에 있다. 주소·포트 변경은 수동 재시작 후 적용되며 OS/방화벽/공유기 변경이나 자동 재시작은 하지 않는다.
- 실제 기관 네트워크 격리, HTTPS, Pi ARM64 실기기 시험은 기존과 같이 별도 운영 확인 항목이다.
