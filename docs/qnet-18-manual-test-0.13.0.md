# Q-Net 18문제 수동 확인 — 0.13.0

이번 0.13.0은 원본 조사·표시와 공통 8P 핀 정의를 제공하는 기반 릴리스다. 공식 문제의 결선 정답과 동작시험은 아직 검증 대기 상태이므로 정확한 결선표를 제공하지 않는다.

## 확인 순서

1. 프로그램을 실행하고 상단 문제 선택을 연다.
2. `Q-Net 공개문제 학습`에 001~018이 정확히 18개 표시되는지 확인한다.
3. 각 카드가 `작성 중` 및 `PDF대조중`으로 표시되는지 확인한다.
4. 001, 009, 010, 018을 차례로 선택한다.
5. 1단계 회로도에서 공식 PDF 7쪽 회로가 표시되는지 확인한다.
6. 확대·축소·드래그 이동으로 작은 접점과 라벨을 읽을 수 있는지 확인한다.
7. 2단계로 이동하면 `공식 결선 데이터 교차검증 중` 안내가 표시되는지 확인한다.
8. 3단계로 이동하면 `공식 동작 정의 교차검증 중` 안내가 표시되는지 확인한다.
9. 자체제작 문제를 선택해 기존 결선 채점과 동작시험이 그대로 열리는지 확인한다.
10. 자유회로 빈보드에서 8P 보조릴레이와 8P 타이머를 설치한다.
11. 두 기구 모두 1~8번 단자가 활성화되는지 확인한다.

## 8P 단자 간단 시험

보조릴레이 X1의 코일을 2–7에 연결한 뒤 다음을 확인한다.

- 무여자: 1–4, 8–5 도통
- 여자: 1–3, 8–6 도통

온딜레이 타이머 T1도 코일 2–7을 사용한다.

- 시간 전: 1–4, 8–5 도통
- 설정시간 후: 1–3, 8–6 도통

실행 스크립트:

```powershell
.venv\Scripts\python.exe scripts\run_qnet_18_smoke_test.py
.venv\Scripts\python.exe scripts\run_qnet_18_smoke_test.py --problem 018
```
