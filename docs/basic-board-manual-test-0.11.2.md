# 0.11.2 통합 기본보드 수동 시험

이 문서는 Q-Net 공식 답안이 아니라 `basic_board_001`과 실제 결선 엔진을 확인하기 위한 기능검증용 결선표다. 실제 전기 작업을 대신하지 않으며 프로그램 안에서만 사용한다. 기본 제어선은 노란색, L1은 갈색, L2는 검은색, L3는 회색으로 선택한다. PE는 연결하지 않는다.

## 시작 방법

1. 프로그램에서 `자유회로`를 연다.
2. 작업공간 이름만 입력하고 `기본보드로 만들기`를 누른다.
3. 하단 상태에 `실제 결선 모드`가 표시되고 초기 전선이 0개인지 확인한다.
4. 외부 기구선 버튼을 누른 뒤 지정한 TB 단자를 누른다.
5. TB와 보드 내부 기구 단자를 표 순서대로 연결한다.
6. `저장`을 누르고 `현재 결선으로 동작시험`을 누른다.
7. 각 시험은 별도 작업공간에서 진행하면 단자 용량과 다른 시험 전선의 영향을 피할 수 있다.

TB 한 번호는 위·아래가 같은 전기 노드다. 화면에서는 외부측 최대 2가닥과 내부측 최대 2가닥을 좌우 물리 포트로 나누어 표시한다. 아래 표는 이 제한과 각 기능 단자의 최대 연결 수를 넘지 않도록 작성했다.

예상 순서:

1. 동작시험에서 `전원 ON`을 누른다.

3. `PB1`을 놓아도 X1 보조 NO(6-3)를 통해 ON이 유지된다.
4. `PB0`을 누르면 NC가 열려 X1이 OFF가 된다.
5. 5번과 8번 전선을 삭제하고 다시 시험하면 PB1을 놓는 즉시 X1이 OFF가 되어야 한다.

예상 순서:

1. 전원을 켜고 PB1을 눌렀다 놓으면 MC1 코일과 자기유지가 ON, M1이 `forward`가 된다.
2. PB0을 누르면 MC1과 M1이 정지한다.
3. 다시 기동한 뒤 `과부하 발생`을 누르면 EOCR 95-96이 열리고 MC1이 복귀하며 RL이 켜진다.
4. `복귀`를 눌러도 MC1은 자동 재기동하지 않는다. PB1을 다시 눌러야 한다.
5. 역상 시험은 27~30번에서 L2와 L3의 MC1 입력을 서로 바꾼다. 엔진 결과가 `reverse`로 바뀌어야 한다.
6. 결상 시험은 35번 또는 36번 한 가닥을 삭제한다. 결과가 `phase_loss`가 되고 결상 가능성 안내가 나타나야 한다.
7. 보호 우회 시험은 별도 작업공간에서 EOCR 95-96 직렬 구간을 제거하고 MC1-12를 PWR-N Net에 직접 연결한다. 트립 후에도 코일 경로가 남고 `EOCR 보호 접점을 우회한 운전 경로` 경고가 나타나야 한다. 이 변형은 위험 진단 확인용이며 정상 결선이 아니다.

## 현재 검증 범위와 제한

- X1·X2 8P 카탈로그는 현재 검증된 코일 2-7과 NO 6-3만 동작 모델에 포함한다. 나머지 핀의 NC 역할은 제조사 자료 확인 전까지 추측하지 않는다.
- T1·T2는 코일 2-7과 ON-delay NO 1-3을 지원한다.
- MC1·MC2의 주접점 1-7·2-8·3-9, 보조 NO 4-10, 보조 NC 5-11과 EOCR 모델은 현재 `unverified` 교육용 정의 상태를 유지한다.
- 실제 전압·전류·차단전류·접촉저항·모터 RPM·토크는 계산하지 않는다.

명령행 자동 확인은 프로젝트 루트에서 다음처럼 실행한다.

```powershell
.venv\Scripts\python.exe scripts\run_basic_board_demo.py
```

마지막에 `모든 기본보드 시험이 통과했습니다.`가 표시되어야 한다.
