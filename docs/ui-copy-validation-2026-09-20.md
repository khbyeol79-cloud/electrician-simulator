# 결선·동작시험 안내 문구 정리 (2026-09-20)

## 수정

- 제어함 결선: 경로 규칙 접기 항목, 저장 주의 문구, 요약 모드의 단자 클릭 안내를 제거했다.
- 회로도 분석 참고창, 자동저장과 저장 상태 표시, 연결된 전선 선택 기능은 유지했다.
- 요구사항 제목의 `PDF 8쪽 ·` 접두어를 화면에서만 제거했다. 서버의 근거·동작 시나리오는 그대로다.
- 미실행 안내 문장을 제거하고 상태는 `미확인`으로 표시한다.
- 실행 완료 상태는 `확인 · 충족` / `확인 · 미충족`으로 구분하고, 검사할 수 없는 상태는 `확인 불가`로 유지한다.
- 실패 원인·다음 조작 안내는 유지한다. 상태 문구가 글자 단위로 줄바꿈되지 않게 했다.
- 전기 엔진·기구 모델·사용자 결선·계정 데이터는 변경하지 않았다.
