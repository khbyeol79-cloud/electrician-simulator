# 0.9.3 구현 상태

## 변경 사항

- TB 한 번호를 세로로 연결된 같은 전위로 유지
- TB 슬롯 용량을 외부측 2가닥과 내부측 2가닥으로 분리 계산
- 일반 기구 단자는 기존처럼 전체 최대 2가닥 유지
- TB 선택·요약 표시에서 `외 n/2`, `내 n/2`를 각각 표시
- 외부측 또는 내부측의 세 번째 전선만 해당 면의 용량 초과로 차단
- 정·역회전 자체제작 문제의 외부 기구선을 포함한 44가닥 테스트 결선표 추가
- `NET_12`의 다중 단자 공통선 예시와 자동 제출 테스트 추가

## 데이터 호환

기존 `max_connections: 2`는 일반 단자에서는 전체 용량, TB 단자에서는 한쪽 면의 용량으로 해석합니다. 기존 결선 초안과 승인 스냅샷의 연결 형식은 변경하지 않았습니다.
