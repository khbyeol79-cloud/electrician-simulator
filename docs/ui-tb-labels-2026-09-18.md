# TB 표시 위치 조정

## 후속 표시 정리

- 그래픽 모드는 TB 외/내 배지 및 일반 단자 연결 수 배지를 모두 숨김.
- 요약 모드는 TB 외/내만 유지하고 일반 단자 2/2 등의 배지는 제거.
- 단자 연결 제한, 접근성 연결 설명, + 배지, 단자별 전선 확인 및 저장 데이터는 유지.
- 공개문제 18개 렌더링 회귀 검사 보강. 프런트엔드 106개, TypeScript 및 운영 빌드 통과.
- 실제 브라우저의 검증용 014 사본(90선): 그래픽 연결 수 배지 0개, 요약 TB 배지 25개·일반 배지 0개 확인.
- 후속 전체 Python 재검증: 452개 통과(222.71초), 기존 Starlette 경고 1개. 고유한 data/dev/pytest-capacity-display-GUID 임시 경로 사용. 문제 검사 오류 0개, 기존 경고 19개.

- TB5 외부/내부 연결 수 배지를 각 회색 슬롯 칸의 위쪽 중앙에 배치.
- TB6은 각 회색 슬롯 칸의 아래쪽 중앙에 배치.
- 표시 명칭은 TB5 / TB6만 출력. 원본 보드 JSON 및 결선 데이터는 변경하지 않음.
- 복수 연결 + 배지는 폭을 24에서 16으로 줄이고 안쪽으로 이동.
- 18개 공개문제의 중앙 정렬, 위/아래 위치, 명칭, + 위치 회귀 검사.
- 컴퓨터 사용 스킬의 브라우저 절차로 격리된 8002 검증 서버의 014(90선)에서 요약/그래픽 모드를 직접 확인.
- 사용자 운영 DB, 작업공간 및 엔진 변경 없음.
