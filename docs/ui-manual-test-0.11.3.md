# 0.11.3 UI·자동저장 수동 확인

이 문서는 0.11.3에서 변경된 자유회로 Delete 키, 자동저장, 오른쪽 패널과 화면 자동 맞춤을 직접 확인하기 위한 순서입니다.

## 1. 실행 전 확인

1. 기존 사용자 DB와 프로젝트 폴더를 백업합니다.
2. 프로그램을 실행하고 하단 버전이 `0.11.3`인지 확인합니다.
3. 기존 자유회로 작업공간이 목록에 그대로 남아 있는지 확인합니다.

## 2. Delete 키와 자동저장 시험용 결선

자유회로에서 `0.11.3 자동저장 시험` 작업공간을 만들고 기본보드를 선택합니다.

다음 결선은 전기 동작 정답이 아니라 UI 저장·삭제 확인용입니다.

| 순서 | 시작 단자 | 도착 단자 | 확인 목적 |
|---|---|---|---|
| 1 | X1-1 | MC1-4 | 첫 번째 전선 생성 |
| 2 | X1-2 | MC1-5 | 연속 편집 자동저장 |
| 3 | X1-6 | MC1-6 | 선택·삭제·복원 |

1. 위 전선 세 가닥을 빠르게 연결합니다.
2. 오른쪽에 `저장 대기 중…` → `저장 중…` → `자동 저장됨`이 표시되는지 확인합니다.
3. 세 번째 전선을 클릭해 하늘색 선택 강조가 표시되는지 확인합니다.
4. 키보드 `Delete`를 눌러 세 번째 전선만 삭제되는지 확인합니다.
5. `실행 취소`를 눌러 삭제된 전선이 복원되는지 확인합니다.
6. `다시 실행`을 눌러 같은 전선이 다시 삭제되는지 확인합니다.
7. 전선을 선택한 뒤 오른쪽 `전선 색상` 선택창에 포커스를 둡니다.
8. `Delete`를 눌러도 전선이 삭제되지 않는지 확인합니다.
9. 전선 색상을 변경하고 `자동 저장됨`을 확인합니다.

## 3. 자동저장 복원과 화면 전환

1. 수동 `저장` 버튼을 누르지 않고 `다른 작업공간`을 선택합니다.
2. 방금 편집한 작업공간을 다시 열어 전선과 색상이 복원되는지 확인합니다.
3. 전선 한 가닥을 추가한 직후 `현재 결선으로 동작시험`을 누릅니다.
4. 동작시험 보드에 방금 추가한 최신 전선까지 표시되는지 확인합니다.
5. 결선 편집으로 돌아온 뒤 작업을 계속할 수 있는지 확인합니다.
6. 프로그램을 정상 종료하고 다시 실행해 같은 작업공간이 복원되는지 확인합니다.

브라우저 또는 프로세스를 강제로 종료하면 마지막 비동기 저장이 완료되지 않을 수 있습니다. 중요한 작업은 `자동 저장됨` 표시를 확인하거나 수동 `저장`을 한 번 누른 뒤 종료합니다.

## 4. 공통 레이아웃 확인

다음 화면 크기에서 각각 확인합니다.

- 1366×768
- 1920×1080
- Windows 최대화
- 창을 가로로 줄였다가 다시 늘린 상태

확인 항목:

1. 오른쪽 작업 패널이 이전보다 넓고 설명·상태 글자가 읽기 쉬운지 확인합니다.
2. 중앙 보드와 오른쪽 패널이 서로 겹치지 않는지 확인합니다.
3. 창 크기를 바꾸면 보드가 현재 작업 영역에 자동으로 맞는지 확인합니다.
4. 보드 크기가 바뀐 뒤에도 전선과 단자 위치가 일치하는지 확인합니다.
5. 단자 클릭과 전선 선택 영역이 실제 그래픽 위치와 일치하는지 확인합니다.
6. 외부 기구선 영역이 사라지거나 잘리지 않는지 확인합니다.
7. TB5·TB6 외부측·내부측 두 가닥 표시가 그대로 유지되는지 확인합니다.
8. 왼쪽 아래 `문제 정보` 카드가 사라졌는지 확인합니다.
9. 상단 `현재 문제` 제목과 문제 변경 기능은 남아 있는지 확인합니다.

## 5. 화면 조절 버튼 확인

| 화면 | 기대 결과 |
|---|---|
| 회로도 분석 | `+`, `-`, `화면 맞춤`, `100%` 유지 |
| 제어함 결선 | 확대·축소 버튼 없음, 보드 자동 맞춤 |
| 결선 화면의 참고 회로도 | 버튼 없음, 마우스 휠과 드래그 확인 가능 |
| 동작시험 | 확대·축소 버튼 없음, 보드 자동 맞춤 |
| 자유회로 편집 | 확대·축소 버튼 없음, 보드 자동 맞춤 |
| 자유회로 동작시험 | 확대·축소 버튼 없음, 보드 자동 맞춤 |

## 6. 기존 전기 동작 회귀 확인

Windows PowerShell에서 프로젝트 루트를 기준으로 실행합니다.

```powershell
.venv\Scripts\python.exe scripts\run_actual_wiring_demo.py
.venv\Scripts\python.exe scripts\run_basic_board_demo.py
```

두 스크립트 모두 마지막에 모든 간단 시험이 통과했다는 메시지가 나와야 합니다.

## 7. 자동 테스트

```powershell
.venv\Scripts\python.exe -m pytest backend\tests desktop\tests -q
cd frontend
npm test -- --run
npm run typecheck
npm run build
```

PowerShell에서 `npm`을 찾을 수 없으면 Node.js LTS를 설치한 뒤 새 PowerShell 창을 열어 다시 실행합니다.

## 8. 오류가 있으면 함께 기록할 내용

- 실행 모드: 데스크톱 또는 웹
- 화면 해상도와 창 크기
- 문제 ID 또는 자유회로 작업공간 이름
- 오류 발생 직전의 클릭 순서
- 자동저장 상태 문구
- `app.log`의 마지막 오류
- 가능하면 오류 화면 캡처
