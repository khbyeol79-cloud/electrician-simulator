# Q-Net 010 FUSE 검증 기록 — 0.14.0-dev2

## 확인된 수정점

Q-Net 010 제어판 배치에는 `F` 기구가 1개만 존재한다. 추가로 제공된 실제 배선 사진에서는 이 한 기구에 외부 전선 4가닥이 연결되며, 참고 풀이의 단자 표기는 두 독립 경로를 `1-2`, `3-4`로 나타낸다.

따라서 dev1의 "FUSE 기구 수 불일치 가능성" 판단을 철회하고 다음 구조로 정정한다.

- 기구 인스턴스: `F` 1개
- 외부 단자: `F-1`, `F-2`, `F-3`, `F-4`
- 내부 정상 도통: `1-2`, `3-4`
- 두 회로 사이: 절연
- 화면 단자 배치: 위 1·3 / 아래 2·4, 두 개의 세로 퓨즈 카트리지를 표현할 수 있는 좌우 2열 구조

## 호환성 정책

기존 `fuse_single_pole_training` 모델은 삭제하거나 의미를 변경하지 않는다. 저장된 자유회로/기존 문제 호환을 위해 그대로 유지하고, 새 `fuse_dual_4terminal_training` 모델을 추가한다.

## 이번 dev2에서 완료한 범위

- 공통 4단자 2회로 FUSE 모델 추가
- 010 `board.json`의 `F`를 한 기구/4결선점으로 수정
- 1-2, 3-4 독립 경로 구조 자동검사 추가
- 네 단자의 보드 위치를 두 세로 퓨즈열 형태로 배치
- 기존 2단자 F 모델 유지 테스트 추가

## 아직 완료하지 않은 범위

현재 제공된 증분 패치에는 전체 `WiringBoard` 렌더러, 결선 채점 서비스, 동작시험 서비스와 관련 API 전체가 포함되어 있지 않다. 또한 이번 입력에는 010 PDF 7~8쪽 전체 원본이 별도 파일로 제공되지 않았다.

따라서 다음 항목은 추측해서 작성하지 않는다.

- FUSE 몸체 내부에 실제 퓨즈 2개를 그리는 전용 렌더러
- 010 `expected_nets`
- `allowed_alternatives`
- TB 동등성 확정
- 010 `operation_tests`
- STOP/EOCR/timer/interlock 우회 음성 테스트
- 백엔드 submit/grading/operation API guard
- 010 `verified` 승격

010은 계속 `draft/unverified`로 유지해야 한다.
