## 결론과 범위

사용자 결선 오류만으로 설명할 수 없는 **공통 기구 모델 오류와 시간 계산 오류**가 있다.
현재 상태를 모든 공개문제에서 동작 원리가 검증된 엔진이라고 보아서는 안 된다.

이번 검수는 공식 PDF의 18개 시퀀스 회로도(7쪽), 동작 설명(8쪽),
기구 내부결선도(9쪽)를 기준으로 했다. 7·9쪽은 원본을 렌더링하여 직접 비교했다.
자료 폴더: `D:/project/elec/전기기능사 공개문제, 2025-08-04`.
파일명: `전기기능사-001-A4, 2025-08-04.pdf`부터 `전기기능사-018-A4, 2025-08-04.pdf`.

자동 검증은 실제 API에서 사용하는 `_practice_runtime_source`와 공통 모델 합성기를 거친
18개 문제의 런타임에 독립 진단 결선을 넣어 실행했다. 사용자 답안을 정답으로 사용하지 않았다.
**18문제 전체 사용자 결선의 모든 동작 시나리오가 통과했다는 뜻이 아니다.**
이번 실행은 Python 엔진 직접 검증이며, 브라우저에서 18문제를 모두 조작한 결과가 아니다.

## 확인된 결함

| 항목 | PDF 기준 | 현재 구현 및 재현 | 영향 |
|---|---|---|---|
| 타이머 순시 접점 | 1–3은 코일 여자 즉시 닫힘. 8–5/6은 시한 전환 | 1–3도 설정시간 이후에 닫힘 | 짧게 눌렀다 놓을 때 자기유지 실패, 순시 표시등/허가회로 지연 |
| 타이머 미사용 단자 | 4는 내부결선 없음 | 1–4 B접점이 존재 | 실제 기구에 없는 통전 경로를 정당한 것으로 계산할 수 있음 |
| FR | 공통 8, B접점 5, A접점 6의 교대 출력 | 5–8 A접점 하나뿐이며 6 출력 없음 | 교대 운전·교대 경보를 재현하지 못함 |
| FLS | 공통 4, B접점 2, A접점 3 | A접점 3–4만 있고 B접점 누락 | 현재 A접점 위주 회로와 별개로 기구 전체 모델은 불완전 |
| 시간 진행 | 중간 접점 전환 이후 새로 여자된 타이머도 남은 시간을 계산 | 모든 타이머 시간을 먼저 일괄 증가시키고 마지막에 접점 해석 | 같은 결선이라도 시간 진행 단위에 따라 결과가 달라짐 |

시간 계산 최소 재현: T1 코일 상시 공급 → T1 시한 A접점 → T2 코일.
두 설정시간의 합을 한 번에 진행하면 T2 미완료, T1 설정시간과 T2 설정시간으로 나눠 진행하면 T2 완료.
사용자 결선·TB 번호·이미지 판독과 무관하게 재현된다.

## 자동 진단 결과

재현 스크립트: `scripts/audit_qnet_engine_against_pdf.py`.

- 실제 모델: **937개 관찰 중 855개 일치, 82개 불일치**.
- 불일치 내역: 타이머 순시/미사용 단자 54개, FR 18개, FLS B접점 9개, 시간 계산 1개.
- 위 세 기구 모델만 **메모리 안에서** PDF대로 바꾼 대조군: **936/937**.
- 대조군에서도 시간 계산 1개는 남는다. 따라서 모델 수정만으로 끝낼 수 없다.
- 937개는 독립적인 937종 문제나 pytest 개수가 아니라 문제별·기구별 상태 관찰 횟수다.

이번 단위 진단에서 정상인 범위:

- X 릴레이의 2개 교환 접점군, MC 주접점·보조 A/B접점의 여자/소자.
- 해당 AC 코일 양단을 뒤집은 경우의 동작.
- PB·LS·SS의 정의된 접점 개폐 및 선택 반대쪽 분리.
- EOCR 공통 95–97 연결, 정상/트립/복귀 접점 전환.
  이 검사는 보호 상태를 직접 설정한 접점 단위 시험이며 UI 과부하 주입 전체 시험과 다르다.
- 타이머 시한 접점의 단독 경계시간·전원 차단 리셋.
- FLS의 전원·센서 결선이 갖춰진 상태에서 A접점 감지/해제.
- FUSE 독립 개방, 직접 단락 감지.

## 수정 권고 순서와 남은 검증

1. 타이머/FR/FLS 모델을 PDF와 맞추고, 문제별 명시 접점 정의와 카탈로그의 충돌도 함께 정리.
2. 시간 진행을 가장 가까운 타이머/FR 전환 시점으로 나누고, 각 전환마다 회로를 다시 계산.
3. 짧은 PB 입력·유지 입력, LS 조합, 모드 전환, T 리셋, FR 위상, EOCR·STOP 우회 등
   18문제별 기대 파형 시험을 구성. FR 시작 위상과 FLS 수위 히스테리시스의 적용 범위도 명시.
4. 그 다음 사용자 답안을 같은 시나리오에 넣어 답안/변환 오류와 엔진 오류를 다시 분리.
5. 실제 화면에서 18문제 결선·동작·저장 왕복을 확인한 뒤에만 사용자 연습용 안정화 완료 판정.

기존 테스트는 잘못된 모델을 기준으로 기대값을 정했을 수 있으므로 통과 개수만으로 원리 검증을 대체하지 않는다.
008·010 사용자 이미지가 없다는 사실은 원본 PDF 기반 엔진 단위 검사에는 장애가 아니며,
이미지 후보를 임의로 생성하거나 공식 정답으로 승격하지 않았다.
