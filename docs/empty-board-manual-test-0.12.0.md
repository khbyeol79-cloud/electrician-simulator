# 0.12.0 빈보드 수동 시험

이 시험은 교육용 논리 모델 확인용이며 실제 전기 안전시험을 대신하지 않습니다.

## 준비

1. 자유회로에서 `빈보드 수동 시험`을 입력하고 `빈보드`를 선택합니다.
2. TB5·TB6만 보이고 중앙 장착칸이 비어 있는지 확인합니다.
3. 오른쪽 팔레트에 내부·외부 기구와 검증 상태가 표시되는지 확인합니다.

## 시험 A: 릴레이 단순 여자

1. 외부 기구 `3상·제어 전원`을 추가합니다.
2. 내부 기구 `8P 보조릴레이`를 추가하고 빈 상단 장착칸을 클릭합니다.
3. `PWR-L → TB5-1`, `TB5-1 → X1-2`를 연결합니다.
4. `X1-7 → TB6-1`, `TB6-1 → PWR-N`을 연결합니다.
5. 동작시험을 시작하고 전원을 ON 합니다.
6. `X1-COIL`이 ON인지 확인합니다.

## 시험 B: START·자기유지·STOP

`3상·제어 전원`, `NC Push Button`, `NO Push Button`, `8P 보조릴레이`를 설치한 뒤 다음 8가닥을 연결합니다.

| 시작 단자 | 도착 단자 | 역할 |
|---|---|---|
| PWR1-L | TB5-1 | 제어 전원 |
| PB1-1 | TB5-1 | STOP 입력 |
| PB1-2 | TB5-2 | STOP 출력 |
| PB2-1 | TB5-2 | START 입력 |
| PB2-2 | TB5-3 | START 출력 |
| X1-2 | TB5-3 | 릴레이 코일 A |
| X1-7 | TB6-1 | 릴레이 코일 B |
| PWR1-N | TB6-1 | 제어 전원 복귀 |

현재 자동 ID는 처음 추가한 NC PB가 `PB1`, 다음 NO PB가 `PB2`가 됩니다. 화면에 표시된 실제 ID가 다르면 같은 역할의 화면 ID를 사용합니다.

자기유지를 위해 다음 2가닥을 추가합니다.

| 시작 단자 | 도착 단자 | 역할 |
|---|---|---|
| X1-1 | TB5-2 | 검증된 릴레이 제1 전환접점 COM |
| X1-3 | TB5-3 | 검증된 릴레이 NO 접점 출력 |

1. 전원 ON 전에는 X1 코일이 OFF인지 확인합니다.
2. START(PB2)를 눌러 X1 코일이 ON 되는지 확인합니다.
3. START를 놓아도 X1 코일이 자기유지되는지 확인합니다.
4. STOP(PB1)을 누르면 X1 코일이 OFF되고 자기유지가 해제되는지 확인합니다.

## 시험 C: 타이머 표시등

1. `3상·제어 전원`, `8P 온딜레이 타이머`, `녹색 표시등`을 추가합니다.
2. `PWR-L → T1-2`, `T1-7 → PWR-N`이 되도록 TB를 거쳐 연결합니다.
3. 검증된 한시 NO 접점 `T1-1/T1-3`과 표시등을 직렬로 연결합니다.
4. 동작시험에서 전원 ON 후 기본 1초가 지난 뒤 표시등 상태가 바뀌는지 확인합니다.

## 편집·저장 회귀

1. 설치 기구를 선택하고 `이동` 후 다른 빈 장착칸을 클릭합니다. ID와 전선 단자 ID가 유지되는지 확인합니다.
2. 연결 없는 기구는 즉시 삭제되는지 확인합니다.
3. 연결된 기구 삭제 시 확인창이 먼저 나오고, 승인 시 관련 전선도 함께 없어지는지 확인합니다.
4. 프로그램을 종료 후 다시 열어 기구 위치·설정·전선 색상이 복원되는지 확인합니다.
5. 전원 없는 빈보드에서 동작시험을 시작하면 `전원 기구를 설치해 주세요.`가 표시되는지 확인합니다.
