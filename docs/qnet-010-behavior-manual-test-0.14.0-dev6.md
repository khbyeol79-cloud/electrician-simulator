## 데이터 정리

수동 확인용으로 생성한 자유회로 작업공간 1개, Q-Net 010 분석 메모, 빈 연습 결선 초안은 확인 직후 해당 ID/API만 지정하여 삭제했다. 확인 시작 시 자유회로 목록은 0개였으며 기존 SQLite 파일이나 다른 사용자·문제 기록은 변경하거나 초기화하지 않았다.

## 미해결

FUSE의 실제 외부 단자 4점과 두 독립 회로는 사진·문제 배치·회로 동작으로 확인했지만, Q-Net PDF 010에는 `1-2 / 3-4`라는 단자번호 자체가 없다. 따라서 이 명칭은 학습용 명명으로 표시하고 공식 검증 완료로 승격하지 않는다.
