# 요약모드 단자별 전선 확인 및 입력 예시 고정

## 변경 내용

- 직전 요약모드의 세로 확대·최소 폭·교대 라벨 배치를 철회하고 기존 보드 좌표와 화면 맞춤을 복원했다.
- 두 개 이상 연결된 단자의 추가 연결 표시는 숫자 없이 `+`만 표시한다.
- 요약모드에서 단자 또는 요약 라벨을 누르면 해당 단자에 직접 연결된 모든 전선만 나타난다. from/to 방향에 무관하며 내부 전선과 외부 기구선을 포함한다.
- 빈 배경을 누르면 표시가 해제된다. 전선 선택 시에는 단자별 표시를 유지한다.
- 요약모드 단자 클릭·드래그로 새 결선이 생성되지 않는다. 새 결선은 그래픽 모드에서 작성한다.
- 회로도 분석 오른쪽 패널을 스크롤 편집 영역과 고정된 하단 예시 영역으로 분리했다.
- 엔진, 사용자 결선 데이터, SQLite 및 문제 정의는 수정하지 않았다.
