# 0.9.1 구현 상태

## 프로젝트 조사 결과

- 기존 버전: 0.9.0
- 로드되는 문제: 자체제작·가상 검증 문제 5개
- 검증된 Q-Net 공개문제: 0/18
- 채점: `expected_nets` 기반 기능 단자 네트워크 비교와 기존 정확 결선 호환
- 동작시험: 사용자 승인 결선을 `ConductiveGraph`로 계산하는 반복 논리 엔진
- 저장: 기존 단일 SQLite DB, 0.9.1부터 LAN 브라우저별 DB 분리
- Desktop: FastAPI 빈 포트 실행 후 pywebview 표시
- Web: `-Lan` 실행 시 `0.0.0.0:8000` 수신

| EOCR | 구현 | 교육용 과부하 주입·수동/자동 복귀 정책 |

| 3상 Motor | 구현 | 정·역 코일, 결상, 상순서, 동시 여자 판정 |

## 0.9.1 변경

- 요약 모드 상대 단자를 기구명 없이 슬롯명만 표시
- 선택 전선에 검은 테두리가 아닌 청록색 외곽 강조선 표시
- Q-Net 18문제 영역과 자체제작 검증 회로 영역 분리
- 일반 사용자용 문제 카탈로그 새로고침 버튼 제거
- `정답`, `기능적으로 동등한 정답`, `동작하지만 오답`, `오답 / 오동작` 결과 분류 추가
- 웹 LAN 브라우저별 SQLite와 동작시험 세션 분리
- 자유회로 정의·결선 저장 및 공통 동작 엔진 세션 API 추가

## 남은 작업

- Q-Net 공개문제 18개의 검증된 회로도·기구 배치·답안·동작시험 데이터 확보 및 입력
- 빈 제어함 기구 배치, 단자 생성과 자유 결선을 제공하는 사용자용 자유회로 편집 화면
- 명시적인 사용자 프로필 생성·전환·관리 UI와 인증
- 자유회로의 단락 가능성·개방회로·충돌 상태를 사용자 화면에서 종합 진단하는 패널
- Windows 실제 장치에서 pywebview/WebView2 수동 실행 확인
