# 도면 이동·번호 표시 후속 수정 (2026-09-17)

## 범위와 원인

- SVG 드래그 중 브라우저 기본 글자 선택/이미지 끌기가 허용되어 파란 선택 표시와 브라우저 선택 도구가 나타났다.
- 분석 화면 배관도는 일반 이미지였으며, 다른 도면과 공통 이동 기능을 사용하지 않았다.
- 번호의 기본 위치가 가로 접점 위 기구 이름, 세로 접점 오른쪽 이름/인접 번호와 가까웠다.
- 넓은 화면에서도 헤더 메뉴가 별도 행을 차지했다.

## 실제 수정

- `CircuitDiagram.tsx`, `useSvgViewport.ts`: 기본 선택/이미지 끌기 방지, 5px 이동 임계값으로 클릭과 드래그 분리, 이동 후 편집기 오작동 방지. SVG 여백을 고려한 화면 거리 1:1 이동. 포인터 기준 휠 확대와 패널 스크롤 분리.
- `analysisAnnotations.ts`, `CircuitAnalysisPage.tsx`: 번호를 가로 접점 아래 좌우, 세로 접점 왼쪽 위아래로 배치. 글자 27→22 SVG 단위. 번호 위치 상하좌우 조정/기본 위치 버튼과 자동저장 추가. 기존 저장 형식 호환 유지.
- `CircuitAnalysisPage.tsx`, `WiringPage.tsx`: 배관도도 공통 SVG 확대/이동 뷰어 사용. 참고창에 저장된 번호 위치 반영.
- `global.css`: 1600px 이상 헤더 한 행 정렬, 목적 문구/현재 문제의 불필요한 가로 여백 축소, 메뉴를 위로 정렬. 좁은 화면에서는 메뉴 줄바꿈 유지.
- 관련 테스트 3개 파일 수정/추가. 엔진, 문제 정의, 사용자 결선 후보, 운영 DB/기존 결선 기록은 변경하지 않았다. dist는 소스에서 빌드했다.

## 실제 브라우저 확인

`http://127.0.0.1:8001`, 기존 분리 검증 프로필 `화면검증0917`, Q001 사용. 사용자의 실제 작업공간을 수정하지 않았다.

| 확인 | 결과 |

| 분석 배관도 드래그 | 이미지 위에서 이동 가능, 금지 드래그 표시 없음 |
| 결선 참고 시퀀스 번호 드래그 | 화면상 36px/27px 이동과 일치, 선택 문자열 없음 |

| 연속 SS/PB0 접점 | C/M, 1/2 입력 후 상하 번호 겹침 없음 |
| 번호 위치 조정 후 즉시 페이지 이동 | 자동저장 후 참고창에 `translate(-8 0)` 반영 |

컴퓨터 사용 스킬에 따라 실제 화면에서 드래그·입력·페이지 전환을 검증했다. 이번에는 공통 뷰어를 Q001에서 검증했으며 전체 18문제의 모든 주석 조합을 시각 재검수한 것은 아니다. 특수한 인쇄 글자와 겹치는 주석은 새 위치 조정 기능으로 보정할 수 있다. 사용자 외부 Edge 창 자체가 아닌 인앱 Chromium 브라우저에서 검증했다.

## 사용 안내

실행 중인 페이지는 새 빌드를 받도록 새로고침한다. 구 화면이 남아 있으면 Ctrl+F5를 사용한다. 번호를 클릭하면 위치 조정 버튼이 보이며, 위치도 번호와 함께 자동저장된다.
