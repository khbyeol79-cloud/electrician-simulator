# 정·역회전·인터록·EOCR 연습 결선표

대상 문제: `forward_reverse_interlock_demo_001`

이 문서는 프로그램 기능을 직접 검증하기 위한 자체제작 연습문제의 결선 예시입니다. Q-Net 공식 공개문제 답안이 아닙니다.

## TB 물리 규칙

- TB 한 번호의 위·아래 단자는 세로로 연결된 같은 전위입니다.
- 외부 기구선이 들어오는 외부측은 최대 2가닥입니다.
- 제어함 내부 배선이 들어가는 내부측도 최대 2가닥입니다.
- 따라서 한 TB 번호에는 `외부 2 + 내부 2 = 총 4가닥`까지 연결할 수 있습니다.

## NET_12 연결 예

| 구분 | 연결 |
| --- | --- |
| TB5 외부측 | `PWR-N → TB5-11` |
| TB5 내부측 | `TB5-11 → MC1-12` |
| 기능 단자 연결 | `MC1-12 → TB6-01` |
| TB6 내부측 | `MC2-12 → TB6-01` |
| TB6 외부측 1 | `RL-2 → TB6-01` |
| TB6 외부측 2 | `GL-2 → TB6-01` |

위 연결은 최종적으로 `GL-2`, `MC1-12`, `MC2-12`, `PWR-N`, `RL-2`를 하나의 Net으로 만듭니다.

전체 44가닥 결선은 같은 폴더의 `test-answer-forward-reverse-0.9.3.json`을 참고합니다.
