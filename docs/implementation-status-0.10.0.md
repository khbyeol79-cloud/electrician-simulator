# 0.10.0 구현 상태

## 구현 완료

- 기존 공개문제 학습과 분리된 자유회로 실험 진입점
- 사용자별 자유회로 작업공간 목록·생성·저장·조회·삭제
- 기존 기능검증 문제의 공개 보드·회로·동작 정의를 재사용하는 시작 보드 3종
- 그래픽·요약 결선, 외부 기구선, 전선 선택 강조, 삭제, 실행 취소·다시 실행
- TB 한 번호의 외부측 2가닥·내부측 2가닥 모델 유지
- 자유회로에서 정답 제출 없이 공통 `OperationEngine` 세션 생성
- PB·LS·Relay·Timer·MC·인터록·EOCR·Lamp·Motor 상태 표시
- 사용자별 SQLite DB와 인메모리 동작 세션 분리
- 빈 결선, 미완성 코일 경로와 엔진 고장 상태의 교육용 진단
- 기존 자유회로 DB 레코드를 읽는 schema 8 비파괴 마이그레이션
- 고립된 그래프 시작 단자 처리 오류 수정

## 기존 기능 보호

- 공개문제의 `expected_nets`와 TB 번호 독립 채점은 변경하지 않았다.
- 자유회로 API와 화면에는 `expected_nets` 또는 정답 데이터를 사용하지 않는다.
- 정·역회전 문제의 동작시험 외부선 렌더링 회귀 테스트를 유지한다.
- Web, LAN 사용자 분리, Desktop pywebview와 오프라인 정적 빌드 구조를 유지한다.

## 제한사항

- 저장소에 검증된 Q-Net 공식 문제는 아직 0/18이며 임의 생성하지 않았다.
- 0.10.0 자유회로는 검증된 시작 보드의 고정 기구 배치를 사용한다.
- 개별 장치의 임의 추가·삭제와 픽셀 단위 자유 배치는 다음 단계다.
- 개방회로 진단은 코일 단자와 현재 전선의 구조적 완성 가능성을 안내하며 모든 원인을 확정하지 않는다.
- 실제 전압·전류·단락전류·접촉저항·열·RPM·토크는 계산하지 않는다.
- Windows 실제 장치에서의 최종 육안 확인은 사용자가 수행해야 한다.
