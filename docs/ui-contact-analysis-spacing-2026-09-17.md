# 접점 입력·탐색·결선 참고창 개선 검증

## 범위와 변경

- 기준 커밋: `0c062cf`, 브랜치: `feature/qnet-all-wiring-capture`.
- 회로도 실제 접점을 클릭해 양쪽 단자의 숫자/글자를 각각 최대 3자 입력한다. 가로는 좌우, 세로는 위아래에 표시한다.
- 공식 회로도 이미지의 원형 단자쌍에서 클릭 영역 좌표만 추출했다. 정답, 접점 역할, 사용자 답안을 생성하거나 공개하지 않았다.
- 클릭 영역 밖의 코일/기타 위치에는 `＋ 다른 위치에 입력`을 사용하고 표시 방향을 선택할 수 있다. 기존 단일 번호 주석은 유지한다.
- 화면 전환 때 500ms 자동저장 대기 중인 마지막 변경도 저장한다. 분석 저장은 사용자·문제별로 순서대로 처리하며, 결선 참고창은 진행 중인 저장이 끝난 뒤 읽는다.
- 결선 참고창에 공식 시퀀스 회로도, 저장한 번호와 메모, 배관·배치도 선택을 연결했다. 확대·축소·이동을 제공한다.
- 왼쪽 진행단계 패널과 완료 수를 제거하고 상단 사용자와 자유회로 사이에 단계 탐색을 배치했다.
- 반복적인 무채점/개인분석 안내와 비활성 설정·도움말 버튼을 제거했다. 상단에 `해당 프로그램은 동작 여부만 판별합니다`를 표시한다.
- 18개 보드는 기존 PDF 대조 행·좌우 순서를 보존하면서 기구 몸체 사이 간격을 62 좌표 단위로 통일하고 행별 중심을 맞췄다. 단자·명판·경로 금지영역을 같은 거리만큼 이동했다.
- 전기 엔진, 요구사항 시나리오, 정답망, 사용자 답안은 변경하지 않았다. 기존 사용자 결선/작업공간을 초기화하거나 마이그레이션하지 않았다.

## 사용 및 인계

- 기존에 실행 중인 데스크톱 프로그램/서버는 완전히 종료 후 다시 실행해야 메모리에 보관된 이전 보드 좌표까지 갱신된다. 브라우저 새로고침만으로는 서버의 보드 캐시가 바뀌지 않는다.
- `frontend/dist`는 직접 수정하지 않고 빌드로 생성했다. Git에는 소스와 보드 데이터만 포함한다.
- `scripts/build_contact_hotspots.py`는 오프라인 좌표 생성 도구이며 OpenCV/numpy가 필요하다. 실제 앱 실행에는 필요 없다.
- 배치 자동 생성기를 다시 실행하면 수동 보강 데이터가 덮일 수 있으므로 무조건 전체 재생성하지 않는다. 이번 보드 갱신은 좌표만 변경하는 별도 스크립트를 사용했다.
- 이번 작업은 UI·저장 연계 개선이며 기존 공식 정답 미검증 상태를 승격하지 않는다. ZIP 생성 및 원격 push는 수행하지 않는다.
