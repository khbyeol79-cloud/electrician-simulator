# 작업공간 팝업 및 공통 사이드바

## 후속 수정: 요약 가독성·기본 보기·예시·확인창

- 요약 라벨을 두 줄로 교차 배치하고 단자 연결 안내선을 표시한다. 추가 연결 개수는 라벨 내부에 표시하며 요약에서 중복 용량 배지를 숨긴다. 실제 결선 수와 오른쪽 상대 단자 목록은 유지한다.
- 요약모드에 한해서 표시용 기구 행 간격을 확장한다. 원본 보드 좌표/저장 결선은 바꾸지 않는다. 좁은 화면은 최소 표시 폭과 스크롤을 사용해 과도한 글자 축소를 피한다. 그래픽 모드 자동 맞춤은 유지한다.
- 18개 공개문제 보드에 인접 단자/긴 외부 기구명/복수 연결 조건의 라벨 사각형 비중첩 테스트 추가. 원본 보드 무변경도 검사한다.
- 동작시험의 공개문제 기본 탭은 배관·배치도. 제어함/시퀀스 전환은 유지한다.
- 분석 오른쪽 아래 가로/세로 슬롯번호 입력 SVG 예시를 추가한다. 실제 답안이 아닌 입력 위치 안내임을 명시한다.
- 작업공간 삭제는 브라우저 기본 confirm 대신 앱 팝업 내부 확인 패널을 사용한다. 취소를 기본 초점으로 두고 취소/Escape로 돌아갈 수 있으며 삭제 대상 이름과 저장 버전 삭제 경고를 표시한다.
- 실제 014 검증용 90선 결선: 요약 라벨 94개 간 겹침 0 확인. 팝업 디자인/취소, 배관·배치도 기본 선택, 분석 예시 그림을 브라우저에서 확인했다. 사용자 작업공간 실제 삭제는 수행하지 않았다.
- 최종 테스트: frontend 105개, Python 452개 통과. TypeScript/production build/문제 패키지 검사 통과. 패키지 기존 경고 19개 유지. git diff --check 통과.

## 후속 수정: PE·삭제·작업시간·스크롤

- PWR-PE뿐 아니라 M1-PE, M2-PE, FLS-PE 등 PE 단자 표시와 연결 전선을 공통 판별 함수로 녹색 처리한다. 일반 전선이나 센서 E1 등은 변경하지 않는다.
- 작업공간 팝업에 삭제 버튼 추가. 확인창에 결선과 저장 버전의 영구 삭제 및 JSON 백업을 안내한다. 취소 시 DELETE를 보내지 않으며 삭제 중 자동저장을 차단하고 기존 저장 대기열 종료 후 삭제한다. 마지막 작업공간 삭제 시 새 빈 작업공간을 생성한다.
- 삭제 후 다음 작업공간 로딩 실패 시 자동저장을 재개하지 않아 삭제된 자료를 재생성하지 않는다.
- 작업공간 선택 목록은 `이름 · N선 · YYYY-MM-DD HH:mm:ss` 형식으로 최근 저장 시각을 표시한다. 데이터베이스 UTC 시각을 브라우저 현지 시각으로 표시한다.
- 회로도 분석 제목의 '메모' 및 오른쪽 메모/관찰 기구/소켓 형식/확인 단자 편집 UI를 제거한다. 기존 저장 값은 지우지 않고 슬롯번호 자동저장을 유지한다.
- 동작시험 보기 탭의 고정 44px 행과 중첩 여백으로 발생하던 세로 스크롤을 내용 기반 높이로 수정한다.
- 실제 브라우저 8002에서 삭제 버튼/날짜/PE 색상/분석 패널을 확인했다. 사용자 자료는 실제 삭제하지 않았으며 삭제 확인·취소 및 재저장 방지는 자동 테스트로 검증했다.
- 도구 모음 실측: clientHeight=43, scrollHeight=43, overflowY=visible. 스크롤 제거 확인.
- 최종 프런트엔드 전체 102개, TypeScript, production build 통과. 문제 검사 23개 오류 0/기존 경고 19 유지.
- 후속 수정 후 Python 전체 재검증: 452 passed, 기존 Starlette 경고 1개. `-m pytest -o addopts='' -q --basetemp <새 data/dev/pytest-pe-ui-GUID 경로>` 사용. `git diff --check` 통과.

## 변경 범위

- 사용자 문제 선택 목록은 공식 공개문제만 표시한다. 내부 기능검증 패키지 및 기존 저장 자료는 삭제하지 않는다. 이전 내부 문제 자동 선택도 해제한다.
- 회로도 분석의 `배관·배치도 (5쪽)` 탭을 `배관·배치도`로 표시한다.
- 제어함 결선 화면에서 상단 오른쪽 `작업공간` 메뉴로 작업공간 선택/추가, 버전 저장/불러오기, JSON 내보내기/가져오기 팝업을 연다. 자동저장 상태는 결선 헤더에 계속 표시한다.
- 팝업은 Escape/닫기/배경 클릭으로 닫으며 키보드 초점을 내부에 유지하고 닫으면 메뉴로 복귀한다. 팝업 안에서는 결선 삭제 단축키를 실행하지 않는다.
- 외부 기구선을 결선 왼쪽 패널로, 기구 상태와 접점 상태를 동작시험 왼쪽 패널로 이동한다. 조작부는 오른쪽에 유지한다.
- 세 화면의 오른쪽 폭은 공통 CSS 변수, 두 화면의 왼쪽 폭도 공통 CSS 변수를 사용한다. 작은 화면에서는 세로 배치한다.
- PWR-PE 선택부와 제어함/동작시험 외부 전선은 녹색으로 표시한다. 기존 결선 JSON의 색상 열거형과 데이터는 변경하지 않는다.
- 엔진, 문제별 회로 정의, 사용자 결선, SQLite 스키마는 수정하지 않는다.
