# Q-Net 008·010·018 통합 개발 인계서 — 0.14.0-dev7

## 확정 기준

- 통합 안정화 식별자: `0.14.0-dev7`
- 대상 브랜치: `feature/qnet-008-018-integration`
- 제품 표시 버전은 정식 릴리스 태그 전까지 `0.13.0`을 유지한다.
- 008·018·010 모두 무채점 기능 연습이며 공식 정답 인증 상태가 아니다.

## 구현 내용

- 공통 카탈로그에 8P FR, 8P FLS, 자동/수동 SS, 2단자 BZ를 추가했다.
- 전기·기구 엔진에 플리커 주기, FLS 전원/전극/수위 조건, 셀렉터 배타 접점, 부저 출력을 합성했다.
- 자유회로와 공개문제가 같은 동작 엔진·고장시험 UI를 사용한다.
- FLS 설치 시 E1·E2·E3 외부 결선점을 생성하고 TB를 거쳐 결선할 수 있다.
- 008·018 공개 문제를 실제 결선 기반 동작시험으로 열고 각각 7개·8개 요구사항을 표시한다.
- 010의 기존 5개 시나리오와 FUSE/EOCR 회귀 동작을 유지했다.
- 008·010·018 보드 모두 한 개 기구에 F-1~F-4 네 단자를 표시한다.
- 모바일 헤더·단계 탐색·동작시험을 단일 열로 재배치하고 전역 1200px 강제 폭을 제거했다.
- `scripts/build_qnet_008_018_public_definitions.py`를 공개 문제 정의 생성 템플릿으로 추가했다. 현재 허용 대상은 008·010·018뿐이다.

## 데이터 보호

- 사용자 후보는 `docs/private`에만 있으며 일반 API·프런트 번들·공개 문제 JSON에 포함되지 않는다.
- ZIP 수집 단계에서 비공개 폴더·테스트·010 내부 후보 스크립트를 제외하고 010 배포 사본의 답안 Net도 제거한다.
- 기존 SQLite, 자유회로 작업공간, 결선 기록은 변경하거나 삭제하지 않았다. 수동 QA는 별도 `ELECTRICIAN_DATA_DIR`에서 수행했다.
