# 직교 배선 경로 엔진

전기적 연결은 단자 ID 쌍으로 저장하며 화면 경로는 별도로 계산합니다. 각 단자는 출구 방향에서 가장 가까운 수평 통로에 연결됩니다. 두 단자가 같은 수평 통로를 공유하면 `단자 → 공용 수평 통로 → 상대 단자` 순서의 최단 직각 경로를 사용합니다. 따라서 `MCCB-L2 → TB5-13`이나 하단 소켓과 TB6 사이의 연결은 좌우 외곽으로 나가지 않습니다.

서로 다른 수평 통로 사이를 이동할 때만 왼쪽·오른쪽 세로 통로 중 거리가 짧은 쪽을 사용합니다. 모든 후보는 금지 영역 충돌과 자기 선분 중첩·교차 여부를 검사합니다. 외곽선은 보드 테두리에 붙지 않도록 통로 안쪽에 배치합니다. 채점은 화면 좌표가 아니라 정규화된 단자 ID 쌍을 기준으로 수행합니다.

요약 모드에서는 원래 단자 위치 가까이에 작은 상대 슬롯번호만 표시합니다. 색상은 상대편 장치의 고유색입니다. 슬롯번호를 클릭하면 오른쪽 작업 패널에서 양쪽의 전체 단자 ID를 확인하고 해당 연결을 선택·삭제하거나 전선 색상을 변경할 수 있습니다.
