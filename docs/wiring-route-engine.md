# 직교 배선 경로 엔진

전기적 연결은 단자 ID 쌍으로 저장하며 화면 경로는 별도로 계산합니다. 인접한 행에서 위·아래 단자가 거의 마주 보는 경우에만 두 소켓 경계 사이의 정중앙을 기준으로 가장 짧은 직각 경로를 만듭니다. 가로 이동이 큰 교차 행 연결, 출구 방향이 서로 마주 보지 않는 연결, 중간 장치에 막힌 연결은 왼쪽 또는 오른쪽 전용 통로로 우회합니다. 외곽선은 보드 테두리에 붙지 않도록 통로의 안쪽에 배치합니다.

경로 선택 순서는 `인접·정렬 단자의 직접 연결 → 금지 영역 검사 → 좌우 외곽 우회`입니다. 모든 경로는 수평·수직 선분만 사용합니다. 채점은 화면 좌표나 경로가 아니라 정규화된 단자 ID 쌍을 기준으로 수행합니다. 요약 모드에서는 연결 자체의 임의 색이 아니라 상대편 장치에 지정된 고유색을 단자 표시에 사용합니다.
