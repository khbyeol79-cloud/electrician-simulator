# 직교 배선 경로 엔진

전기적 연결은 단자 ID 쌍으로 저장하며 화면 경로는 별도로 계산합니다. 서로 마주 보는 위·아래 단자 사이에 빈 행간 통로가 있으면 해당 통로를 이용해 가장 짧은 직각 경로로 연결합니다. 각 수평·수직 선분은 `forbidden_areas`와의 교차 여부를 검사하며, 소켓이나 장치가 막는 경우에만 거리 비용이 낮은 왼쪽 또는 오른쪽 외곽 통로로 우회합니다.

경로 선택 순서는 `빈 행간 직접 연결 → 충돌 없는 직각 후보 → 좌우 외곽 우회`입니다. 모든 경로는 수평·수직 선분만 사용합니다. 기존 선과 겹치는 경우 연결 순서에 따라 lane 간격을 추가합니다. 채점은 화면 좌표나 경로가 아니라 정규화된 단자 ID 쌍을 기준으로 수행합니다.
