# 회로도 분석 참고창

제어함 결선 화면의 오른쪽 패널은 현재 문제의 회로도와 1단계에서 사용자가 입력한 소켓번호를 함께 표시한다.

- 회로도 분석 화면과 동일한 `CircuitDiagram` 컴포넌트를 재사용한다.
- 참고창에서는 접점 선택과 답안 수정이 비활성화된다.
- 확대, 축소, 화면 맞춤, 100% 초기화, 마우스 휠, 드래그 이동을 지원한다.
- 입력값은 `electrician.circuitDraft.{problem_id}.v{version}` 로컬 저장 키에서 읽는다.
- 문제 ID 또는 버전이 달라지면 다른 문제의 입력값을 섞어서 표시하지 않는다.
- 참고창은 사용자의 입력을 보여줄 뿐 정답 데이터나 채점 결과를 노출하지 않는다.

1단계에서 답을 수정한 뒤 2단계로 이동하면 참고창이 최신 입력값을 다시 읽는다. 상단 초기화 기능으로 회로도 분석 입력을 지우면 참고창도 비워진다.
