# 공통 장치·소켓 카탈로그

`socket_types.json`은 배선 작업자가 베이스를 정면에서 본 실제 핀 위치만 정의합니다. 릴레이와 타이머의 내부 접점 번호는 이 파일에 넣지 않습니다.

`device_types.json`의 `electrical_definition_status`가 `unverified`인 장치는 실제 단자와 내부 접점 자료가 아직 검증되지 않은 상태입니다. 확인되지 않은 번호를 추정하여 `reviewed` 또는 `verified`로 바꾸지 마십시오.

`device_behaviors.json`은 기구 모델이 고유하게 가진 로컬 단자, 코일, 접점, 기본 상태와 항상 도통되는 내부 연결만 정의합니다. `MC1` 같은 인스턴스 ID, 정·역회전 역할, EOCR 보호 대상, 인터록 상대 기구, 사용자 결선, TB5·TB6 번호와 문제 정답은 이 파일에 넣지 않습니다.

`reviewed`는 현재 자체제작 문제와 자동 테스트를 대조했다는 의미이며 실제 제조사 자료 검증 완료를 의미하지 않습니다. `source_note`에 제한사항이 있는 모델은 후속 검증 전까지 교육용 정의로만 사용합니다.
